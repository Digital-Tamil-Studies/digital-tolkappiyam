# தொல்காப்பியம் · Tholkappiyam reader

A static site for reading Tholkappiyam, laid out like kural.inayathalam.in:
அதிகாரம் tabs across the top, the இயல் list on the left, and the நூற்பாக்கள் on
the right. Hovering an underlined word shows its dictionary gloss; clicking pins
the full entry. The top search box searches sutras and headwords; the அகராதி
tab has its own word lookup and an alphabetical index.

Routes (hash based): `#/a/<atikaram>`, `#/i/<iyal>`, `#/s/<n>` (single sutra,
← → keys step through), `#/d`, `#/d/l/<letter>`, `#/d/w/<word>`, `#/d/e/<id>`,
`#/q/<text>`, `#/q/<text>/<atikaram>`.

> **Not yet reviewed.** The English translation, the 1961 commentary, the
> word glosses and the dictionary cross-references were all extracted
> automatically (OCR, AI vision transcription, rule-based matching) and have not
> been checked by hand. Expect errors; see [Data status](#data-status) below.

## Layout

```
app/                  the website, and the only folder published to GitHub Pages
  index.html, assets/app.js, assets/styles.css   hand-written
  data/thol.js, data/dict.js, data/notes.js      generated by scripts/build.py

scripts/              everything that builds the data and the site (see below)

data/
  source/             originals as received; never edited
  manual/             inputs edited by hand; fixes go here
  work/               intermediate files written by scripts; don't edit
  final/              tholkappiyam.csv, the end product the site build reads; don't edit

docs/                 extraction notes and deployment guide
.github/workflows/pages.yml   publishes app/ to GitHub Pages on every push to main
```

| Folder | Contents | Edit by hand? |
|---|---|---|
| `data/source/` | `pmuni0100.html` (Project Madurai), `thol_dictionary_metadata_all_5947.csv` (3,805 senses), the two PDF scans (not in git) | never |
| `data/manual/` | `transcribed_1961/` (vision transcription, the source of record for the 1961 edition, + `INSTRUCTIONS.md`), `token_map.csv` (token → headword fixes) | yes |
| `data/work/` | `ocr/`, `ocr_1961/` (Tesseract output), `scan_1961/png/` and `tessdata/` models (not in git), `commentary_1961.csv`, `reports/` | no, scripts rewrite these |
| `data/final/` | `tholkappiyam.csv`: 1,603 sutras with Tamil, English and 1961 columns | no, scripts rewrite this |

Scripts:

```
parse_tholkappiyam.py   source HTML -> tholkappiyam.csv (Tamil columns only)

ocr_english.sh          renders the English PDF and OCRs every page into data/work/ocr/
parse_english.py        data/work/ocr -> english_edition_no, title, transliteration, translation columns
                        + data/work/reports/english_ocr.csv

ocr_1961.sh             renders/strips the 1961 scan and OCRs it into data/work/ocr_1961/
parse_commentary.py     data/manual/transcribed_1961 -> data/work/commentary_1961.csv + review report
merge_commentary.py     appends edition_no_1961/title_1961/poem_1961/commentary_1961 to tholkappiyam.csv

build.py                runs both build stages
build_corpus.py         stage 1: csv -> structure + sutras
build_dictionary.py     stage 2: dictionary -> entries, lookup index, token map, refs
                        + data/work/reports/gloss_coverage.csv
serve.py                local preview server for app/
package_site.py         zips app/ into dist/
```

## Build and run

```
python3 scripts/build.py          # writes app/data/*.js and data/work/reports/gloss_coverage.csv
python3 scripts/serve.py          # http://localhost:8050/
python3 scripts/package_site.py   # dist/tholkappiyam-YYYYMMDD.zip
```

Only the Python standard library is used. The site also opens directly from
`app/index.html` without a server.

## English edition columns

`data/final/tholkappiyam.csv` also carries, per sutra, the title, transliteration and
English translation from Dr V. Murugan's *Tolkāppiyam in English* (2001) and
that edition's sutra number (`english_edition_no`; the book merges two pairs of
sutras and splits two others, so its numbering drifts from the CSV's by one in
places). They are produced by `ocr_english.sh` + `parse_english.py`; see
`docs/NOTES_english_extraction.md`. Regenerating the CSV with `parse_tholkappiyam.py`
drops these columns, so run `python3 scripts/parse_english.py data/work/ocr` afterwards.

## 1961 commentary columns

`tholkappiyam.csv` also carries the 1961 edition's title, sutra text and Tamil
commentary (தெளிவுரை) for every sutra. They come from `data/work/commentary_1961.csv`;
run `python3 scripts/merge_commentary.py` to (re)apply them, also after
regenerating the CSV. See `docs/NOTES_commentary_1961.md`.

## Improving the gloss coverage

The build resolves each word of the text to a dictionary headword: exact match
first, then stripping a sandhi consonant (க்/ச்/த்/ப்) or a common inflection
(ும், ின், ே, …). `data/work/reports/gloss_coverage.csv` lists every distinct word with
its count, the key it matched and the method (`exact`, `fallback`, `miss`,
`override`). To fix a wrong fallback or fill a miss, add a row to
`data/manual/token_map.csv`:

```
token,key,note
வரூஉம்,வரு,verb வரு-தல்
என்னும்,என்,not என்ன
சொல்லே,-,suppress: no useful entry
```

`key` must be one of the dictionary lookup keys (a headword with its
superscript removed, or the stem of a `X-தல்` verb). `-` suppresses the match.
Rebuild to apply.

## Dictionary references

References such as `(தொல். 1051:2)` follow a different edition's numbering.
The build locates the intended sutra by matching the quoted fragment against
sutras near that number; resolved references become links. Unresolved ones are
shown as plain text.

## Data status

Apart from the Project Madurai text, everything the site shows was produced
automatically and **has not been reviewed by a person yet**.

| Data | How it was made | Known gaps |
|---|---|---|
| English title, transliteration, translation | Tesseract OCR of the scan, parsed by `scripts/parse_english.py` | OCR errors in diacritics and wording; sutra 1217 has no translation in the book. Review list: `data/work/reports/english_ocr.csv` |
| 1961 title, sutra text, commentary | AI vision transcription (Claude) of the scan, cross-checked against Tesseract OCR | 92.4% letter agreement between the two readings; 583 sutras carry warnings, 4,083 items to check in `data/work/reports/commentary_1961_review.csv` |
| Word glosses | Rule-based matching of each word to a dictionary headword | 71% of words matched, and about a third of those by a fallback (sandhi or suffix stripping) that can pick the wrong word. Every match is listed in `data/work/reports/gloss_coverage.csv` |
| Dictionary references `(தொல். N)` | Matched to sutras by quoted text, since they use another edition's numbering | 2,635 of 3,554 resolved; the rest are shown as plain text |

Corrections are welcome. Fixes go into `data/manual/`: the transcriptions for
the 1961 edition and `token_map.csv` for glosses.
